# Regression Checklist

适用于 `v1.5.0` 之后的人工回归。目标不是穷举，而是快速覆盖最常用、最容易因前端重构回退的路径。

## 环境

- 启动服务并确认能正常打开首页
- 如浏览器已缓存旧版前端，先强制刷新一次
- 如使用 PWA / Service Worker，确认已拿到最新 `sw.js`
- 登录后保存离线快照再退出，桌面顶部和 iPhone“更多 → 退出”都应进入退出页并清除 API / 缩略图缓存和本地 Viewer 状态；未登录时在线请求旧缩略图不得从缓存直接返回

## 登录与首页

- 打开首页，确认页面可正常加载，无白屏
- 如启用了密码，确认登录页可进入，登录后能回到主界面
- 首页默认进入“全部文件”
- 首次进入“全部文件”默认使用 Eagle 式网格；用户切换后的网格/列表偏好可恢复

## 左侧导航

- Eagle 密码文件夹在桌面侧栏和 iPhone 侧栏 / 搜索中显示锁定状态和“受保护”文案，不显示真实素材数量；点击后出现安全边界说明，不发起文件夹内容请求
- 密码文件夹及全部后代素材不得出现在全部素材、标签、搜索、最近、Eagle 智能文件夹、相似素材或离线快照；直接请求文件夹返回 `423`，相关素材详情 / 缩略图 / 原文件端点返回 `404`
- 锁定说明在 iPhone 上以避让安全区的底部卡片呈现，关闭按钮可触控，点击遮罩或按 `Esc` 可关闭；说明不得要求用户在远程 Viewer 输入 Eagle 文件夹密码

- 文件夹树可展开 / 折叠
- 点击文件夹后，右侧内容区切换到对应结果
- 当前文件夹路径会在左侧正确高亮
- 内容区顶部显示当前位置面包屑；文件夹视图可从路径逐级返回资料库或上级文件夹
- 标签搜索可过滤标签列表
- 点击标签后，内容区切换到标签结果
- 素材卡片主文件夹和列表行路径 chip 可点击；点击后应进入对应文件夹视图，同步左侧导航高亮、滚动定位并短暂高亮原素材，并且不误开素材详情或预览
- 素材卡片首个标签和列表行标签显示为可点击 chip；点击后应进入对应标签视图，并且不误开素材详情或预览
- 素材卡片和列表行的格式 chip 可点击；点击 `.png` / `.pdf` 等格式后应添加“格式”筛选 chip，并把当前视图收窄到同扩展名素材
- 点击“最近 7 天 / 30 天”后，内容区切换正确
- 收藏 / 待整理 / 已处理 / 智能视图 / 疑似重复入口均可从侧栏打开

## 搜索与跳转

- 普通关键字搜索返回结果
- 输入 `#标签名` 可跳到标签视图
- 输入 `/文件夹名` 或路径片段可跳到文件夹视图
- 搜索框聚焦 / 输入时显示建议；`#` 建议标签、`/` 建议文件夹，键盘上下和点击均可选择
- 清空搜索后，页面能回到合理的当前上下文
- `Cmd/Ctrl+K` 可打开命令面板，并可跳转常用视图
- 内容工具栏显示当前视图概览，包括总大小、主要类型数量、已载入/总数（分页视图）以及有标签/有来源数量；移动端可横向滚动查看
- 桌面顶部工具栏保持 Eagle 式分组密度：视图/缩略图密度、资源库刷新/筛选/智能视图、统计/重复/命令、导出/外观之间有轻量分隔；内容筛选条是紧凑二级栏，不应挤压面包屑和视图概览
- 当前视图中存在来源 URL 时，概览应显示 Top 来源域名 chip；点击域名 chip 后应添加“来源站点”筛选 chip，并把当前已载入结果收窄到该域名
- 有来源 URL 的素材在移动端卡片、列表行和 Inspector 来源区显示可点击来源域名；点击后应按同一来源站点筛选，并且不误开素材详情
- 内容工具栏“复制视图”应复制当前文件夹 / 标签 / 搜索 / 清单 / 智能视图及排序、类型、高级筛选参数链接；如果 Inspector 正打开，不应把当前素材 `item=` 混入视图链接
- 移动端 workbar 的分享按钮和“更多 → 分享视图”应复制或调用系统分享当前文件夹 / 标签 / 搜索 / 清单 / 智能视图及排序、类型、高级筛选参数链接；链接不应混入当前打开素材 `item=`

## 筛选与工具面板

- 高级筛选面板可打开、应用和清空筛选
- 高级筛选面板顶部显示规则摘要：打开时展示当前已应用筛选数量和核心条件；修改表单但未应用时，摘要切换为“待应用规则”，提示需要点击“应用筛选”刷新当前视图
- 启用主色并调整颜色容差后，结果按 Eagle `palettes` 元数据过滤；保存视图后颜色条件可恢复
- 含 `palettes` 的素材卡片显示紧凑主色色板；点击卡片色板会按该颜色筛选，并且不误开 Inspector 或预览
- 移动端搜索 sheet 空输入时，如当前已载入视图存在 `palettes`，应显示“主色浏览”分组，按当前视图 Top 色板展示色块入口；点击色块后应设置“主色”高级筛选和默认容差，并刷新当前视图
- 移动端长按含 `palettes` 的素材时，快捷操作 sheet 应显示带真实色块的“同主色”入口；点击后应关闭 sheet、设置“主色”高级筛选和默认容差，并刷新到相近主色素材
- 移动端“主色浏览”分组只基于当前已载入素材统计，不应暗示是全库统计；色块入口应保持紧凑，不撑破 quick grid
- 桌面端悬停素材卡片时显示预览 / 详情 / 收藏 / 待整理 / 已处理快捷按钮；点击收藏、待整理或已处理后角标、按钮高亮和侧栏数量即时更新，不误开 Inspector
- 高级筛选支持格式、标签 / 备注 / 来源 / 来源站点 / 收藏 / 待整理 / 已处理状态；输入 `.png` 或 `png` 都应按同一扩展名过滤并可保存视图
- 应用高级筛选后，内容工具栏显示当前筛选 chip；点击单个 chip 可移除对应条件，点击“清空”可移除全部条件
- 带高级筛选参数的 URL 刷新后可恢复筛选 chip 和结果
- 智能视图面板提供内置整理预设（未标签 / 未来源 / 无备注 / 未收藏 / 待整理 / 未处理 / 已处理成果池），点击后可直接进入对应临时智能视图
- 智能视图结果为空时，应显示面向当前整理队列的空状态；“调整筛选”打开高级筛选，“浏览资料库”清空筛选并回到全部文件
- 侧栏“智能视图”区始终显示内置整理队列，并在其下方显示用户保存的智能视图或保存入口
- 命令面板可搜索并打开内置整理预设
- 智能视图面板可保存当前排序、格式和高级筛选；保存后会出现在侧栏“智能视图”区并显示条件摘要；管理面板中的自定义智能视图卡片应额外显示范围、类型、筛选和排序规则 chips，便于复制链接前确认规则
- 智能视图面板中每个自定义视图可复制链接，复制出的 `#view=smart&smart=<名称>` 链接在另一台设备打开后应恢复对应智能视图
- 智能视图面板可导出自定义智能视图 JSON；导入 JSON 后同名视图应覆盖、不同名视图应追加，并同步到侧栏“智能视图”区
- 通过 `/#view=smart&smart=<名称>` 刷新或在手机浏览器重新打开后，能恢复对应智能视图
- 索引状态面板可显示扫描统计
- 疑似重复视图可打开，空库时显示空状态

## 列表与网格

- 列表视图可正常显示名称、路径、格式、时间等信息
- 移动端列表模式下，文件名下方应显示格式、尺寸/大小和来源域名等紧凑摘要胶囊，帮助在横向表格压缩时快速扫读；桌面端仍保持原有列表来源 chip 和列信息
- 移动端列表模式下，文件名区域下方应显示预览/打开、详情、选择三个动作胶囊；点击预览/打开应打开全屏预览或原文件，点击详情应打开 Inspector，点击选择应进入/切换选择状态，按钮文案/高亮应在“选择 / 取消选择”之间即时同步，且不误触发行点击
- 切换到网格视图后，缩略图和文件封面卡渲染正常
- 无缩略图文件在网格里不会出现异常放大、空列或居中留白
- 桌面网格卡片保持 Eagle 式紧凑素材管理器视觉：hover 只显示轻量蓝色选框和操作浮层，不把卡片抬升成作品集样式；文件名、尺寸、格式和来源徽标在缩略图下方清晰可读
- 点击素材后 Inspector 以资产档案形式显示：预览、素材类型、文件名、状态标记、规格卡片、组织信息、来源 / 备注和技术信息分区
- 桌面 Inspector 保持 Eagle 式属性栏密度：预览区有透明棋盘背景，规格区为紧凑属性表，字段标签/值对齐；底部操作按“预览 / 输出 / 整理 / 更多”分组且不挤压内容滚动区域
- 可预览素材的 Inspector 预览区显示“点按预览”提示，点击或键盘 Enter / Space 可直接进入全屏预览；不可预览文件不应显示可点状态
- Inspector“相关”分区可跳到同格式搜索、同类型视图、同构图筛选和不小于当前尺寸筛选；跳转后 Inspector 关闭且内容区结果刷新
- Inspector 底部可直接预览、复制 Markdown 引用、复制素材信息、加入待整理、标记已处理；更多菜单仍可下载、分享链接、复制 HTML / 文本引用和收藏
- 收藏 / 待整理 / 已处理状态在网格卡片右上角、列表行名称旁均有可见标记，切换后即时更新
- 收藏 / 待整理 / 已处理、复制链接 / 信息 / 引用、复制图片和刷新资源库后应出现短暂 toast，且不遮挡底部导航、批量条或预览操作栏
- 从文件多的目录切到文件少的目录，布局不会残留上一页列数
- 缩略图密度滑杆可调整列数；少量素材不会被拉伸为大卡片
- 桌面端在网格卡片或列表行右键可打开素材菜单，预览 / 详情 / 打开文件夹 / 同来源站点 / 同主色 / 收藏 / 待整理 / 已处理 / 链接 / 复制 / 下载入口可用；没有来源或色板的素材不显示对应入口；打开文件夹后应定位并高亮原素材

## 移动端浏览

- 小于等于 768px 时，首次进入“全部文件”默认使用网格卡片而不是横向滚动表格
- 卡片始终显示素材名称和基础格式/尺寸信息，不依赖鼠标悬停；移动端素材卡应呈现 app-like 胶片卡质感，包含圆角容器、缩略图底部柔和渐层、清晰状态胶囊和触摸按压反馈
- 底部导航可在“资料库 / 收藏 / 待整理 / 搜索 / 更多”之间切换，并正确高亮当前入口
- 底部导航 tab 点按或键盘激活时应出现短暂 pulse / 按压反馈；打开搜索或更多 sheet 时对应 tab 高亮并设置展开态，关闭 sheet 后应恢复到真实当前视图入口高亮
- 内容工具栏在移动端显示横向可滑的快速筛选胶囊；点击“未处理 / 待整理 / 未标签 / 未来源 / 有来源”应立即刷新当前视图并与高级筛选 chip、URL 状态同步；点击“清筛”应清空当前高级筛选
- 移动端内容区顶部 workbar 应显示当前视图名称、类型、已载入/总数、排序和筛选摘要；切换文件夹、标签、搜索、收藏或智能视图后应即时更新，不应残留上一个视图
- 文件夹、标签、搜索、清单、最近、智能视图和重复项之间的切换应创建视图级浏览历史；iPhone 边缘返回 / 浏览器返回应恢复上个视图，排序、筛选和 Inspector 开合只更新当前历史项；存在站内历史时，移动端 workbar 显示返回按钮，回到首个视图后自动隐藏
- 移动端 workbar 下方应显示类似 App Home 的“继续工作”卡片：主卡展示继续预览、最近素材名、当前视图类型/名称和数量，状态 chip 展示远程 Vault、离线快照和筛选数量，下方横滑入口包含上次素材、继续审片、待整理和离线快照；有最近查看记录且素材可预览时，“继续预览”直接打开该素材全屏预览，不可预览时打开详情；无最近记录时进入未处理审片；“上次”显示最近素材名并直接打开该素材详情，记录不可解析时回退到最近查看清单；待整理数量、筛选数量和快照时间应随状态变化刷新
- 移动端启用高级筛选后，workbar 下方应显示可横滑的具体筛选 chip；点击单个 chip 应移除对应筛选，点击“清空”应清空所有高级筛选，并同步内容结果、桌面筛选 chip、底部“更多”徽标和 URL 状态
- 移动端 workbar 的远程状态应随远程 Vault 在线 / 检查中 / 离线和离线快照保存状态更新；点击 workbar 右侧分享、搜索、更多按钮应分别分享当前视图、打开搜索 sheet、打开更多 sheet
- 点击底部“搜索”打开移动端搜索 sheet；输入关键词可搜索，输入 `#` / `/` 可跳标签或文件夹，空状态下显示收藏、待整理、未处理、成果池、最近查看、整理预设、常用标签和文件夹快捷入口；类型快筛可切换全部 / 图片 / 视频 / 音频 / 文档 / 其他并刷新当前视图；排序快控可切换最近 / 名称 / 大小 / 格式和升降序；布局快控可切换网格 / 列表，小 / 中 / 大缩略图密度会实际改变移动端网格列数
- 移动端搜索 sheet 空输入时，快捷入口应按“继续工作 / 我的智能视图 / 整理队列 / 主色浏览 / 来源站点 / 快速浏览”分区显示；“继续审片”入口更突出；保存过智能视图时，“我的智能视图”应按最近保存优先显示常用筛选入口，点击后进入对应智能视图；超过快捷展示数量时应提供“管理全部”入口；主色区应显示当前已载入视图的 Top 色板，来源站点区应显示当前已载入视图的 Top 来源域名；所有入口点击后仍应关闭 sheet 并进入对应视图或筛选
- 点击移动端搜索 sheet 的 Top 来源域名，应设置“来源站点”高级筛选、同步筛选 chip / URL 状态，并刷新当前视图；长域名不应撑破 quick grid
- 移动端搜索 sheet 的“继续工作”区应显示已处理数量、最近查看数量、待整理数量和离线快照状态；点击“离线快照”应触发保存当前视图离线快照
- 移动端搜索 sheet 中保存离线快照成功后，“继续工作”区的离线快照时间 / 数量应立即刷新；更多面板远程状态卡和继续工作条也应同步更新，不需要关闭重开页面
- 保存离线快照成功后，已打开的移动端批量输出抽屉应短暂显示“离线快照已更新”的 saved 状态，然后恢复在线/离线输出能力说明；已打开的全屏预览远程提示、移动端 workbar、更多面板和搜索快捷入口也应同步刷新
- 移动端搜索 sheet 在设备离线或远程 Vault 不可达时，应在快捷入口顶部显示状态卡，说明正在使用快照或需要重连；状态卡中的“重连”应触发远程检查，“保存”应触发当前视图离线快照
- 移动端搜索 sheet 可从手柄或标题区向下拖动关闭；拖动时背景透明度和 sheet 位移应跟手，未超过阈值应回弹，结果列表滚动不应误触发关闭
- 移动端搜索 sheet 顶部提供 `# 标签`、`/ 文件夹`、关键词三枚提示胶囊；点击 `# 标签` 或 `/ 文件夹` 应填入对应前缀并聚焦输入框，结果应按快捷入口 / 标签 / 文件夹 / 搜索建议分组显示，分组计数准确，结果行应按标签 / 文件夹 / 搜索 / 命令显示不同类型标识
- 移动端搜索无结果时显示可操作空状态；点击空状态内 `# 标签`、`/ 文件夹` 或关键词入口应复用同一模板填充逻辑并聚焦输入框
- 移动端内容工具栏的快速筛选胶囊应显示状态点；启用筛选后胶囊有明确 active 态，底部“更多”tab 显示当前高级筛选数量徽标，清空筛选后徽标消失
- 点击底部“更多”打开移动端工具面板，顶部远程状态卡显示在线 / 离线、只读挂载、PWA 和离线快照状态；点击“重连”会检查 `/health` 并刷新资源库；更多面板可进入侧栏、智能视图、未标签 / 未来源 / 待整理 / 未处理 / 成果池预设、最近查看、高级筛选、分享当前视图、疑似重复、索引状态、命令面板、刷新和外观切换
- 更多面板的“当前工作入口”卡片应显示当前视图类型、名称、载入/排序/筛选摘要和快照状态；切换文件夹、标签、搜索、收藏或智能视图后重新打开更多面板应同步更新，不残留旧视图
- 点击“当前工作入口”卡片内的“分享视图”应复制或调用系统分享当前视图 URL；点击“保存视图”应以当前视图、排序、类型和高级筛选创建智能视图，并同步侧栏智能视图入口；点击“离线保存”应保存当前视图离线快照，完成后卡片内快照状态应立即更新

- 更多面板状态卡下方显示“继续审片 / 最近查看 / 离线快照”启动条；最近查看数量和离线快照时间/数量应随本地状态更新，点击三个入口分别进入未处理审片、最近查看清单和保存当前离线快照
- 点击“更多 → 继续审片”应打开“未处理队列”，并自动预览第一张可预览素材；若没有可预览素材，应保留队列列表并显示轻量提示
- 在移动端“更多”中点击“离线快照”，应主动保存当前视图索引、当前素材元数据和可用缩略图；成功后显示保存数量 toast，Service Worker 尚未控制页面时应提示下次打开后可用

- 移动端“更多”显示离线数据管理卡：快照视图、保存时间、成功/总项目数和浏览器本站存储占用可见；可更新快照，清除前必须确认；清除只删除 API / 缩略图离线缓存，保留应用外壳、收藏和智能视图状态
- 每次保存离线快照都应按当前视图路由更新“离线视图库”，同一路由覆盖更新时间、不同文件夹 / 标签 / 搜索 / 智能视图累计保留最近 8 个；移动端“更多”可横滑查看并直接打开，断网时命中已缓存索引与缩略图；清除离线数据后目录同步清空
- 断开网络或远程 Vault 不可达时，页面顶部应出现全局远程状态条；点击“重连”会检查 `/health`，成功后刷新资源库并短暂显示“远程 Vault 已恢复”后收起
- 收藏 / 待整理有内容时，底部导航显示数量徽标；清空后徽标消失
- 空收藏 / 空待整理 / 空已处理显示专用空状态，点击“浏览资料库”能回到全部文件并关闭 Inspector
- 整理清单可从智能视图面板导出 / 导入 JSON；导入时应合并收藏、待整理、已处理和最近查看，不清空现有清单，并刷新侧栏 / 底部徽标数量
- 网格卡片、列表行、Inspector、全屏预览 HUD 和移动端长按面板均可设置 1–5 星评分；再次点击当前星级可清除评分，所有入口即时同步且不写入 Eagle Vault
- 高级筛选可按最低 1–5 星过滤结果，并可保存到智能视图；评分降到当前门槛以下时素材应立即从结果中移除
- 评分随 Viewer 状态跨设备同步，并包含在整理清单 JSON 导出 / 导入中
- 侧栏“工作集”可创建带名称和颜色的自定义集合；创建后立即出现侧栏入口，打开后显示正确素材数量与彩色标识，刷新和跨设备同步后仍保留
- 卡片右键菜单、Inspector、全屏预览“更多”、移动端长按面板和批量选择均可打开工作集选择器；加入后素材显示工作集色标，再次点击同一工作集可移出
- 工作集视图支持分享/复制 URL、刷新恢复、空状态和批量移出；删除工作集前必须确认，删除只影响 Viewer 状态，不删除或移动 Vault 素材
- 整理清单 JSON 导出 / 导入包含工作集；导入同 ID 工作集时合并素材列表，不清空现有内容
- Inspector “上下文”区同时区分只读的 Eagle 备注和可编辑的 Viewer 笔记；输入后 650ms 自动保存，失焦或 `Cmd/Ctrl+Enter` 立即保存，刷新与跨设备打开后内容保持
- 有 Viewer 笔记的素材在卡片 / 列表状态角标和移动端长按状态区显示笔记标记；从右键菜单、长按面板或全屏预览“更多”点击“编辑 Viewer 笔记”应打开 Inspector 并聚焦编辑器
- 普通关键词搜索同时命中 Viewer 笔记；高级筛选可按有无 Viewer 笔记收窄，并可保存为智能视图；当前筛选条件下新增或清空笔记后，不符合条件的素材自动移出
- 整理清单 JSON 导出 / 导入包含 Viewer 笔记；笔记写入 Viewer 状态文件，不修改 Eagle `metadata.json`
- Inspector “相似素材”横向轨道不包含当前素材，按本地元数据匹配显示分数与最多三个依据；点击卡片切换到对应素材，桌面可滚动，iPhone 可横滑且页面本身不出现横向溢出
- 远程 Vault 不可达且相似结果未缓存时，轨道显示联网提示，不影响 Inspector 其余只读信息和已缓存预览
- 断网后修改评分、收藏 / 待整理 / 已处理、Viewer 笔记、工作集或智能视图，顶部与移动端远程状态应显示“待同步”；刷新页面后本机修改仍在，不被服务器旧状态覆盖
- 恢复系统网络或点击“重连”后，待同步状态自动补传并变为“已同步”；若服务器 revision 已由另一台设备推进，应三方合并本机相对基线的增删与远端新修改，409 不能直接清空本机离线修改
- 通过 `/#view=collection&collection=favorite` 刷新或重新打开后，仍停留在收藏视图
- 打开素材详情或预览后，侧栏“最近查看”数量增加；进入 `/#view=collection&collection=recentViewed` 可继续浏览最近打开的素材
- 打开素材详情或预览后，移动端搜索 sheet 的“继续工作 / 最近查看”和更多面板的“最近查看”入口应立即同步最新数量，不需要关闭页面或刷新
- 通过带 `item=<素材ID>` 的 URL 刷新或重新打开后，能恢复对应素材 Inspector
- 内容区位于顶部时下拉可触发刷新资源库；普通上下滚动不应误触发
- 长按素材卡片可打开快捷操作面板，顶部应显示当前素材状态胶囊（已选中 / 已收藏 / 待整理 / 已处理，或未加入清单），操作按“打开 / 整理 / 输出”分区；预览 / 详情 / 文件夹 / 选择 / 收藏 / 待整理 / 已处理 / 链接 / 信息 / Markdown / 下载入口可用；点击链接 / 信息 / Markdown 应显示复制反馈并短暂延迟后收起面板；点击下载应显示开始下载反馈并收起面板；点击文件夹后应定位并高亮原素材，松手后不应误开 Inspector
- 移动端含收藏 / 待整理 / 已处理状态的素材卡片右上角应显示带文字的紧凑状态胶囊；切换状态后胶囊文字和颜色应即时同步，不需要长按或打开详情才能辨认整理状态；桌面端和列表行仍保持紧凑图标显示
- 长按快捷操作面板中，有来源 URL 的素材应在“打开”区显示“来源”入口；点击后关闭面板并按同一来源站点筛选当前视图；无来源素材不显示该入口
- 移动端快捷操作面板可从手柄或标题区向下拖动关闭，拖动时面板和背景应跟手；未超过关闭阈值时应回弹，面板内容滚动不应误触发关闭
- 轻触/按住移动端素材卡片时应立即出现轻微按压反馈；开始滚动或取消触摸后反馈消失，长按超过阈值才打开快捷操作面板
- 移动端 Inspector 的“预览 / 待整理 / 已处理 / 更多”操作均可点击；“更多”中可下载、收藏和复制（如支持）
- 移动端 Inspector 打开时内容区出现半透明遮罩，抽屉层级高于遮罩；点击遮罩空白处可关闭详情
- 移动端 Inspector 顶部显示抽屉手柄；点击手柄可在半屏 / 全屏档位间切换，上拉手柄或标题栏可展开，下滑超过阈值可关闭
- 移动端 Inspector 顶部摘要栏显示当前素材名称、格式/尺寸/大小/标签/来源摘要和“上拉展开 · 下滑关闭”提示；关闭再打开不会残留上一个素材摘要
- 移动端 Inspector 打开后，左右横滑可切换上一项 / 下一项；上下滚动详情不应误触发切换
- 关闭 Inspector 后，内容区应滚回并短暂高亮刚查看的素材，避免在长列表中丢失位置
- 查看或预览过素材后，内容区右下角显示“回到当前项”浮动胶囊；滚远后点击应回到并高亮当前素材，切到无关视图后应自动隐藏
- Inspector 底部操作栏不被 iPhone 安全区域遮挡
- 移动端全屏预览底部显示“详情 / 收藏 / 待整理 / 已处理 / 更多”五个主操作，并呈现接近原生 app 的浮动 tab bar 质感；收藏、待整理和已处理切换后按钮状态即时更新；“更多”弹出分享链接、复制信息、Markdown 引用和下载原文件，并通过 `aria-expanded` 同步开合状态；完成输出动作后更多菜单应自动收起；点击下载显示开始下载反馈后按钮应恢复可用状态
- 移动端全屏预览顶部 HUD 应显示格式、尺寸、大小、来源站点、文件夹、标签和收藏 / 待整理 / 已处理状态，并作为悬浮信息卡覆盖在暗场渐层之上；点击底部收藏、待整理或已处理后，HUD 内对应状态 pill 应立即同步出现或消失；点击来源站点、文件夹或标签应关闭预览并跳到对应筛选/视图
- 移动端全屏预览应使用近乎不透明的独立暗场，不再透出底层 Inspector、素材列表或底部导航；打开时背景区域应进入 `inert` / `aria-hidden` 状态且焦点落到“关闭全屏预览”，关闭后恢复原有可访问状态并回到当前素材
- 关闭全屏预览后，内容区应滚回并短暂高亮刚预览的素材；在预览内左右切换素材时不应闪回上一张的列表位置
- 移动端图片 / 音频全屏预览支持下滑关闭，未达到阈值时应跟手回弹；PDF / 文本预览仍应优先保留内容滚动，不被下滑关闭误触
- 在“未处理队列”中打开全屏预览后，点击底部“处理”应标记已处理并自动前进到下一张可预览素材；队列末尾应关闭预览并刷新列表
- iPhone Safari 非主屏幕模式下显示“添加到主屏幕”引导卡片，关闭后短期内不再打扰，且不遮挡底部导航
- 添加到主屏幕后以独立 PWA 窗口打开，底部导航和 Inspector 不被系统安全区域遮挡
- iPhone 添加到主屏幕后应使用清晰的 180 PNG 图标；PWA manifest 应声明稳定的 `/` 应用 ID 与作用域，并提供 180 / 192 / 512 PNG 图标资源，重新安装或更新后不应出现泛白图标或重复应用身份
- 独立 PWA 窗口没有显式 hash 启动时，应自动恢复 14 天内的上次浏览文件夹 / 标签 / 搜索 / 智能视图 / 素材详情，并显示短暂 toast；带快捷入口 hash 启动时不应被上次位置覆盖；超过 14 天的旧恢复记录应被忽略并清理，显示轻量提示后回到资料库，避免回到过期上下文
- PWA manifest 应提供全部素材、搜索 Vault、最近查看、收藏、待整理、继续审片和成果池快捷入口；“搜索 Vault”快捷入口应使用 `action=search` 并直接打开移动端搜索面板；“最近查看”快捷入口应进入 `recentViewed` 清单；“继续审片”快捷入口应使用 `action=review` 并直接进入未处理队列的第一张可预览素材
- Service Worker 已缓存某个只读 JSON 接口后，断开网络再次进入对应文件夹 / 标签 / 搜索 / 最近 / 全部素材视图，应能渲染离线快照并提示“正在浏览离线快照，重连后刷新 Vault”；没有缓存的接口仍应显示离线空状态
- 离线或远程 Vault 不可达但当前视图仍有缓存结果时，主内容区顶部应显示离线 / 快照提示条，说明结果可能不是实时远程 Vault，并提供“重连”入口；恢复在线后提示条应随状态刷新
- 离线或远程 Vault 不可达时，如果当前主内容区没有素材和子文件夹，普通空状态应替换为专用离线空状态，说明这不是资料库为空，并提供“重连”和“保存快照”入口
- 离线或远程 Vault 不可达时，列表行、桌面右键菜单和移动端长按快捷操作 sheet 的“下载”入口应显示为“需联网”并不可点击；共享下载动作应弹出“下载原文件需要连接远程 Vault”，避免误以为原文件已离线缓存
- 离线或远程 Vault 不可达时，Inspector 更多菜单和移动端全屏预览“更多”里的下载入口也应显示为“需联网”或禁用态；批量条和移动端输出抽屉中的“打包下载”应变为“需联网”并阻止 ZIP 请求；恢复在线后当前 Inspector、列表、已打开的全屏预览底栏、批量条和输出抽屉应同步恢复下载入口
- 离线或远程 Vault 不可达时，已打开的全屏预览内应显示远程降级提示卡，说明当前只能浏览快照 / 缓存预览、原文件下载需重连，并提供“重连”和“保存快照”入口；恢复在线后提示卡应自动移除
- 已保存离线快照的图片在原文件请求失败时，应自动回退到已缓存缩略图并继续显示全屏预览；预览内必须标明“离线预览 / 缩略图质量”，原文件下载仍保持需联网状态；缩略图也未缓存时才显示明确的不可用提示
- 离线快照不应缓存 `/api/state`、原文件 `/file`、批量下载或其他写入请求
- 收藏 / 待整理 / 已处理 / 最近查看清单在远程 resolve 失败但本地已有素材快照时，不应被清空；应继续显示本地清单并提示重连后更新

## 增量加载

- “全部文件”向下滚动时能继续自动加载
- “最近 30 天”向下滚动时能继续自动加载
- 文件夹、标签和搜索结果较多时，向下滚动也能继续自动加载
- 已加载全部内容时，底部状态文案正确
- 滚动回上方时，不出现明显整页重绘或错乱

## 详情与预览

- 图片 Inspector 的“审片标记”可先输入意见，再进入画面定位模式；点选图片内容后生成带编号的点位，编号在不同窗口宽度下仍落在相同比例位置，点击编号可定位对应评论
- 视频 / 音频 Inspector 可用 `01:23` 或秒数创建时间标记；普通评论、点位和时间标记均可删除，卡片显示标记数量，搜索能命中标记文字
- 审片标记只写 Viewer 状态；离线创建后显示待同步，重连可同步，导出 / 导入整理清单时标记不会丢失

- 点击单个文件可打开右侧 Inspector
- Inspector 中上一项 / 下一项按钮可用
- 键盘 `← / →` 可在详情中切换前后项
- Inspector 中的文件夹路径和标签 chip 可点击跳转到对应文件夹 / 标签视图；文件夹跳转后应定位并高亮原素材，同步 URL 与左侧导航状态
- Inspector 的“分享链接”可复制 / 调用系统分享当前素材深链接
- Inspector、移动端长按 sheet、桌面右键菜单和全屏预览“更多”均提供“分享原文件”；iPhone / 支持 Web Share 文件的浏览器应把 64 MB 内原文件连同正确文件名和 MIME 类型交给系统分享，“存储到文件”或 AirDrop 可继续使用；取消分享不报错
- 离线、浏览器不支持文件分享、文件类型不可分享或原文件超过 64 MB 时不得把完整大文件继续读入内存，应提示改用下载；页面链接分享仍然可用
- Inspector、桌面右键菜单、移动端长按 sheet 和移动端全屏预览底栏均可复制素材信息（名称、类型、尺寸、大小、路径、标签、深链接等）
- Inspector 和桌面右键菜单可复制 Markdown / HTML / 文本引用；移动端长按 sheet 可复制 Markdown 引用
- 图片预览正常
- 图片预览支持放大、缩小、适应窗口与原始尺寸
- 移动端图片全屏预览支持双击 / 双 tap 在适应窗口和细节放大之间切换；缩放后再次双击应还原，且不误触发左右切换或下滑关闭
- 移动端图片全屏预览支持双指捏合缩放；捏合过程不应触发左右切换、下滑关闭或双 tap 缩放
- 移动端图片放大后支持单指拖动画面查看细节；拖动过程不应触发左右切换或下滑关闭，适应窗口后拖动偏移应清零
- 图片全屏预览提供水平翻转和顺时针 90° 旋转；变换后缩放、拖动画面和左右切换未达阈值回弹仍应保留当前变换，不修改 Vault 原文件
- 视频全屏预览除浏览器播放控件外提供水平翻转、90° 旋转、0.5× / 1× / 1.25× / 1.5× / 2× 倍速循环切换和循环播放开关；当前状态应通过高亮及 `aria-pressed` 可见，退出预览后不写回素材
- 全屏预览支持上一项 / 下一项、计数显示、键盘 `← / →` 切换；移动端左右滑动有跟手位移反馈并可切换预览素材
- 移动端全屏预览下滑关闭时背景应随手势变浅，松手未关闭时恢复原位
- 通过关闭按钮、点击遮罩或 `Esc` 关闭全屏预览时，都应使用同一关闭逻辑并回到当前预览素材在列表中的位置
- “回到当前项”浮动胶囊不应遮挡移动端底部导航、全屏预览底栏或 Inspector 操作栏
- 全屏预览底部显示当前视图可预览素材胶片条，当前项高亮；点击胶片条缩略图可跳转到对应素材，移动端胶片条应像可横滑素材轨，不遮挡底部操作栏
- 音频素材应被识别为可预览；打开后显示音频播放器卡片、时长 / BPM 等元数据和原生播放控制，加载失败时保留可理解的错误提示
- `ttf` / `otf` / `woff` / `woff2` 应显示远程字体样张；网格卡片与 Inspector 使用实际字体渲染，全屏 Type Lab 可编辑文字、切换中文 / Latin / 数字预设并调整字号，整个过程不安装字体、不写入只读 Vault
- iPhone 字体全屏预览应在 HUD 与底部五个动作之间完整显示，样张可编辑、字号滑杆可触控，左右切换保留且纵向编辑/滚动不误触下滑关闭
- `doc` / `docx` / `xlsx` / `pptx` 网格卡片应显示对应 W / X / P 封面；打开 Inspector 后按需显示旧版 Word 可读文字、Word 正文、首表或首张幻灯片摘要，列表加载本身不应批量请求全部文档预览
- Office Quick Look 全屏舞台应只读显示旧版 Word 可提取段落、Word 段落/表格、Excel 首个工作表和 PowerPoint 幻灯片文字；损坏、加密、过大或旧版 `xls` / `ppt` 文件应明确引导下载，不执行宏、不调用本机 Office
- Legacy Word Quick Look 在 macOS 应使用系统 `textutil`、Docker 应使用 `antiword`；提取过程必须限制文件大小、执行时间和输出量，失败时不得暴露服务器路径，也不得在 Vault 内生成转换文件
- iPhone Office Quick Look 应完整位于顶部 HUD 与底部胶片条之间；Word 正文可纵向滚动、Excel 表格可横纵滚动、PPT 幻灯片可连续浏览，内容手势不得误触下滑关闭
- `xmind` 网格卡片应显示 M 导图封面；打开 Inspector 后才按需请求主题摘要，列表加载本身不应批量请求全部导图预览
- XMind Quick Look 在桌面应显示工作表、中心主题和分支关系；只读取主题树，不展开附件、不运行链接，损坏、加密、过大或无法识别的导图应明确引导下载
- iPhone XMind Quick Look 应完整位于顶部 HUD 与底部胶片条之间，并收敛为可纵向滚动的知识树；滚动主题不得误触下滑关闭
- Graffle、Numbers、MindNode 等浏览器不支持但含 Eagle 缓存图的素材，应在卡片与 Inspector 显示缓存图，并可进入标有 `EAGLE CACHE QUICK LOOK` 的全屏暗房；列表加载不应请求原始专有文件
- Eagle 缓存 Quick Look 应支持适应窗口、1:1、缩放、翻转和旋转；下载仍必须返回原始扩展名文件，缓存图缺失或损坏时应明确提示，不能把占位图冒充可用预览
- iPhone Eagle 缓存 Quick Look 应位于顶部 HUD 与底部胶片条之间，支持双击、捏合和放大后拖动；页面不得横向溢出，手势不得误触相邻素材或关闭
- 全屏预览顶部 HUD 显示素材名称、格式、尺寸/大小、文件夹和标签摘要；点击文件夹 / 标签 chip 可关闭预览并跳转到对应视图，移动端不遮挡底部操作栏
- 当前视图至少有 2 个可预览素材时，全屏顶部应显示序号、播放 / 暂停与 3 / 5 / 8 秒间隔；桌面可用空格或 `P` 切换，手机可直接点按；自动播放跨过当前 120 条边界时继续增量载入，走到末尾后循环，切到后台时不推进，关闭预览后停止
- `pdf` 可在详情中预览，悬停支持大预览
- `txt` 可在详情中预览，网格卡片可显示摘要
- 缩略图失败但原文件可预览的图片，列表 / 网格中应有回退显示
- 含 `palettes` 的素材在 Inspector 显示可点击色板；点击色板后关闭 Inspector，并按该色值与默认容差筛选相近主色素材；音频素材显示时长与 BPM（如元数据存在）

## 多选与批量操作

- 选择至少 2 张图片后，批量托盘“对比图片”可用；只选择一个图片或图片不足 2 张时按钮禁用，混选文档时仅图片进入对比台，超过 4 张时载入前 4 张并提示
- 桌面对比台按 2 张双栏、3–4 张 2×2 排列；滚轮或工具栏缩放、拖拽平移在“同步”开启时作用于全部图片，关闭同步后只作用于当前图片；“适应”、`1:1`、双击复位、`+` / `-` / `0` 和 `Esc` 可用
- iPhone 对比台每页显示一张图片，可横滑分页且页面无横向溢出；顶部保留适应、1:1 和关闭，底部素材名、格式、尺寸、序号与缩放比例可读

- 点击勾选框只改变选中状态，不应误开详情
- 移动端长按素材打开 quick sheet 后，可点 `选择 / 取消选择` 进入或退出多选；桌面右键菜单也提供同等选择动作
- 素材被选中后，网格卡片显示清晰选中胶囊和蓝色高亮，列表行显示高亮左边线；取消选择后样式消失
- 移动端素材卡左上角应使用半透明圆形选择器而不是浏览器原生白色复选框；未选时保持低干扰，选中后显示蓝色勾选并同步卡片高亮，读屏名称应包含对应素材名
- 进入选择状态后，继续点击网格卡片或列表文件名 / 缩略图应切换该素材的选中状态，而不是打开 Inspector 或预览；网格双击也不应触发预览
- 在网格和列表中先选择一个素材，再 Shift 点击另一个素材、列表文件名或列表缩略图，应按当前排序顺序选中两者之间的连续范围；不在选择模式时 Shift 点击素材也应进入选择语义而不是打开详情 / 预览；批量条提示 Shift 范围选择
- 已选中的网格卡片和列表行应有明显选中态
- 选中多个文件后，Inspector 应关闭
- 批量条能显示数量、总大小、类型构成、当前视图已选/已载入范围，并展示已选素材缩略图预览；点击缩略图可滚动定位到对应素材
- `全选 / 反选 / 取消` 行为正确
- 批量条可将已选素材加入收藏 / 待整理 / 已处理；在收藏、待整理或已处理视图中可将已选素材移出当前清单，并刷新侧边栏数量与素材角标
- 在未处理 / 已处理成果池 / 待整理等智能队列中执行对应收藏、待整理或已处理操作后，当前队列应自动刷新，已不符合筛选条件的素材从结果中移走
- 移动端批量条显示为底部整理胶囊，优先展示全选 / 反选 / 取消 / 收藏 / 待整理 / 已处理 / 移出当前队列；复制、导出、打包下载等输出动作应折叠到“输出”按钮中
- 点击移动端批量条“输出”应打开底部输出抽屉，显示已选数量、总大小和输出能力卡；在线时能力卡说明 ZIP 原文件可打包，离线或远程 Vault 不可达时说明复制链接、复制信息、Markdown、CSV 和 JSON 仍可用但 ZIP 需要重连；抽屉应提供复制链接、复制信息、Markdown 引用、CSV 导出、JSON 导出和 ZIP 打包下载；复制/导出动作完成后抽屉可自动收起；ZIP 打包下载应显示“准备 ZIP…”状态，开始下载后提示并收起抽屉
- 移动端批量整理动作完成后，底部整理胶囊应短暂高亮反馈，并在批量条提示区显示“已加入 / 已移出 N 个素材…”的完成状态；反馈结束后恢复选择提示，且 toast 不被遮挡
- 桌面批量条可复制已选素材的深链接列表、完整素材信息与 Markdown 引用列表
- `导出已选` 左键导出 CSV，右键导出 JSON
- `打包下载` 能正常触发 ZIP 下载

## 快捷键与交互

- 桌面顶部“自适应画廊”按钮可在瀑布流、自适应和列表之间切换；自适应模式按素材宽高比拼行，没有重叠、断层或页面横向溢出
- 自适应画廊中调整缩略图密度、开合 Inspector 或改变窗口宽度后应重新计算行高；素材顺序、选择状态和当前 Inspector 不丢失
- iPhone 搜索面板选择“自适应”后，画布形成紧凑图片墙，横图与竖图保持合理比例，无页面横向溢出；刷新后保留该设备的布局偏好
- 桌面顶部“画布显示设置”可在瀑布流 / 自适应 / 列表之间切换，并实时调整缩略图大小；选择“完整”后图片不被裁切，切回“填满”后恢复铺满
- 画布设置可分别隐藏 / 显示名称、规格、格式与来源徽标、收藏与审片标记；全部卡片信息关闭时不应留下空白详情区
- iPhone“更多 → 画布设置”可打开适配安全区域的设置面板；手机与桌面分别保留布局、密度及显示偏好，刷新后生效且不修改 Vault
- 桌面侧栏显示 Vault 自带的“Eagle 智能文件夹”及嵌套层级、规则摘要和命中数量；点击后结果符合 Eagle 原生格式 / 标签等规则，侧栏保持当前项高亮
- Eagle 智能文件夹结果支持现有排序、类型筛选、增量加载、Inspector 和素材预览；复制链接或刷新后通过 `view=eagle-smart&eagleSmart=...` 恢复同一入口
- iPhone“更多 → Eagle 智能文件夹”可定位到远程 Vault 的原生自动分类，搜索 sheet 也会把这些入口独立分组；打开结果后底部“更多”保持高亮且页面无横向溢出
- Eagle 智能文件夹保存离线快照后，断网仍能恢复智能文件夹树、当前规则结果与缩略图；整个过程不写入 Vault 的 `metadata.json`

- 桌面侧栏“全库色谱”可打开颜色索引，顶部色带、统计数据、色组卡片和素材缩略图正常；点击色带或色组后进入全部素材视图，并带对应主色与 `±72` 容差筛选
- iPhone“更多 → 全库色谱”可打开同一视图；色带可横滑、色组两列无横向溢出，点击后底部导航回到资料库且筛选 chip 可见
- 桌面侧栏“随机模式”可打开 24 项接触表；刷新或复制链接后，同一 Seed 应恢复相同素材顺序，“再洗牌”应更换 Seed 与结果
- 随机漫游切换图片 / 视频 / 文档 / 音频后，结果只包含对应类型；空类型显示明确空状态，不误报 Vault 为空
- iPhone“更多 → 随机漫游”可打开同一视图；素材卡片横向分页、贴合停靠且页面无横向溢出，点卡片可打开 Inspector，底部“换一条路径”可生成新 Seed
- 随机漫游保存离线快照后，断网打开对应 Seed 链接仍可恢复接触表和缩略图；原文件操作继续明确提示需连接远程 Vault

- `j / k` 或 `↑ / ↓` 可移动当前焦点
- `Enter` 可预览当前焦点项
- `Space` 可切换当前焦点项选中状态
- `Shift+Space` 可从上一个选择锚点范围选择到当前焦点项；`Cmd/Ctrl+A` 可全选当前视图；选择状态下 `Esc` 应先取消选择
- `Esc` 可关闭预览层或 Inspector

## 刷新与缓存

- 点击“刷新资源库”按钮后，页面不会报错
- 刷新后当前视图仍能恢复到合理状态
- 前台浏览时每 45 秒轻量检查远程 Vault，至少每 5 分钟执行一次深度元数据检查；从后台停留超过 30 秒再回来时立即深度检查
- 检测到更新时不自动打断当前预览、详情或多选，而是显示“远程 Vault 有新内容 / 载入更新”；确认载入后刷新树、标签和当前视图，并保留当前工作入口
- 升级版本后，浏览器能拿到新的前端静态资源
- PWA 检测到新版本后应在后台完成下载并激活新的 Service Worker，但不强制刷新正在使用的页面；随后显示“新版本已准备好”提示，“稍后”不打断当前浏览，“立即更新”应刷新页面并通过独立模式路由恢复回到当前工作位置；旧版客户端不支持提示时，新 Worker 也应能完成接管并在下次打开时升级；从后台重新回到页面时最多每 15 分钟检查一次更新
- 新版本提示与移动端搜索、更多、快捷操作、批量输出或 Inspector 同时存在时，当前模态 sheet 应位于更新卡片上方，更新卡片不能遮挡输入框、操作按钮或详情内容
- 收藏、待整理、已处理或智能视图后，顶栏同步状态从“同步中”恢复为“已同步”
- 两台设备同时修改旧版本状态时，后提交设备收到最新状态，不会静默覆盖

## 最低通过标准

- 无白屏、无主路径报错
- “全部文件 / 最近 / 文件夹 / 标签 / 搜索 / 详情 / 多选 / 下载 / 预览” 都至少走通一次
- 未发现明显交互回退或布局错乱

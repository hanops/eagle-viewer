# Regression Checklist

适用于 `v1.5.0` 之后的人工回归。目标不是穷举，而是快速覆盖最常用、最容易因前端重构回退的路径。

## 环境

- 启动服务并确认能正常打开首页
- 如浏览器已缓存旧版前端，先强制刷新一次
- 如使用 PWA / Service Worker，确认已拿到最新 `sw.js`

## 登录与首页

- 打开首页，确认页面可正常加载，无白屏
- 如启用了密码，确认登录页可进入，登录后能回到主界面
- 首页默认进入“全部文件”
- “全部文件”默认使用列表视图

## 左侧导航

- 文件夹树可展开 / 折叠
- 点击文件夹后，右侧内容区切换到对应结果
- 当前文件夹路径会在左侧正确高亮
- 标签搜索可过滤标签列表
- 点击标签后，内容区切换到标签结果
- 点击“最近 7 天 / 30 天”后，内容区切换正确

## 搜索与跳转

- 普通关键字搜索返回结果
- 输入 `#标签名` 可跳到标签视图
- 输入 `/文件夹名` 或路径片段可跳到文件夹视图
- 清空搜索后，页面能回到合理的当前上下文
- `Cmd/Ctrl+K` 可打开命令面板，并可跳转常用视图

## 筛选与工具面板

- 高级筛选面板可打开、应用和清空筛选
- 保存视图面板可保存当前视图，并可重新打开保存项
- 索引状态面板可显示扫描统计
- 疑似重复视图可打开，空库时显示空状态

## 列表与网格

- 列表视图可正常显示名称、路径、格式、时间等信息
- 切换到网格视图后，缩略图和文件封面卡渲染正常
- 无缩略图文件在网格里不会出现异常放大、空列或居中留白
- 从文件多的目录切到文件少的目录，布局不会残留上一页列数

## 增量加载

- “全部文件”向下滚动时能继续自动加载
- “最近 30 天”向下滚动时能继续自动加载
- 文件夹、标签和搜索结果较多时，向下滚动也能继续自动加载
- 已加载全部内容时，底部状态文案正确
- 滚动回上方时，不出现明显整页重绘或错乱

## 详情与预览

- 点击单个文件可打开右侧 Inspector
- Inspector 中上一项 / 下一项按钮可用
- 键盘 `← / →` 可在详情中切换前后项
- 图片预览正常
- 图片预览支持放大、缩小、适应窗口与原始尺寸
- `pdf` 可在详情中预览，悬停支持大预览
- `txt` 可在详情中预览，网格卡片可显示摘要
- 缩略图失败但原文件可预览的图片，列表 / 网格中应有回退显示

## 多选与批量操作

- 点击勾选框只改变选中状态，不应误开详情
- 选中多个文件后，Inspector 应关闭
- 批量条能显示数量、总大小、类型构成
- `全选 / 反选 / 取消` 行为正确
- `导出已选` 左键导出 CSV，右键导出 JSON
- `打包下载` 能正常触发 ZIP 下载

## 快捷键与交互

- `j / k` 或 `↑ / ↓` 可移动当前焦点
- `Enter` 可预览当前焦点项
- `Space` 可切换当前焦点项选中状态
- `Esc` 可关闭预览层或 Inspector

## 刷新与缓存

- 点击“刷新资源库”按钮后，页面不会报错
- 刷新后当前视图仍能恢复到合理状态
- 升级版本后，浏览器能拿到新的前端静态资源

## 最低通过标准

- 无白屏、无主路径报错
- “全部文件 / 最近 / 文件夹 / 标签 / 搜索 / 详情 / 多选 / 下载 / 预览” 都至少走通一次
- 未发现明显交互回退或布局错乱

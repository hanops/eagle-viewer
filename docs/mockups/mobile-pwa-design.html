DESIGN NOTES / V2相对 v1 改了什么

  • 废弃紫蓝渐变库卡片 → 换成工具感 status strip + mono 计数条，信息密度更高。
  • 方形网格 → 不规则瀑布流（签名）：保留原图宽高比，永不裁切，2 列，gap 7px。
  • 字体重选：Archivo（UI）+ JetBrains Mono（计数/路径/状态/时间全部走 mono），v1 的 Instrument Serif 在禁用名单。
  • 深色为默认（媒体浏览器 → 内容前置），浅色为系统跟随的第二主题，见第 06 屏。
  • 签名交互：预览跟手下拉关闭（05 屏），图片缩小圆角化、背景透出网格；超过 25% 视口高度释放即关闭。
  • 单一强调色 oklch(74% .13 250)：只用于激活 Tab、搜索聚焦、主按钮、文件夹图标，其余全灰阶。

INTERACTION REVIEW交互已全部落稿

  • 🔴 已修：列表屏可滚动。原 overflow:hidden 把首页瀑布流下半截裁掉，现改为纵向滚动，浏览器里可真实下滑 review。
  • 🟢 已加：预览双指缩放 + 点按隐藏栏。见 07 屏：纯黑沉浸、无上下栏，底部 PINCH/ZOOM 与 TAP 提示；缩略图小字可放大阅读。
  • 🟢 已加：左右滑切换兄弟项。见 04 屏左右露出相邻缩略图（iOS Photos 同款 peek 暗示），横滑=换图、下滑=关闭，互不冲突。
  • 🟢 已加：状态页入口。点首页状态条 → 进完整状态页(06)；首屏齿轮图标已移除，消除歧义。
  • 🟢 已定：下滑关闭。位移 >25% 视口高度（或快速下甩）释放即关，图片缩小圆角化、背景透出网格。
  • 🟢 搜索防抖 300ms + 结果数/耗时走 mono，与工具风签名一致；空结果/无匹配态一帧待补（不影响主流程）。

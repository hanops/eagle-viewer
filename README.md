# Eagle Vault Viewer

把 NAS 或远程主机上挂载的 Eagle 资源库带到浏览器：在无法安装 Eagle 的电脑、平板和手机上浏览、搜索、预览与整理个人清单。Vault 始终只读挂载，不修改库内任何文件。

**版本**：v1.5.1（2026-05-08）

**License**：MIT

## 功能

- **浏览**：解析 Eagle 库的文件夹树（`metadata.json`），按文件夹展示素材（各 `*.info/metadata.json`）
- **视图**：全部文件、最近 7 天 / 30 天、按文件夹、按标签、搜索
- **增量加载**：全部文件、最近、文件夹、标签与搜索视图按批次自动续载，滚动到底部时继续加载更多，避免一次性渲染全量结果
- **Eagle 式工作区**：紧凑三栏结构，包含资源库树、分组工具栏、二级筛选条、可调密度素材画布和 Inspector；默认深色网格，素材卡片采用桌面素材管理器式轻量 hover 选框、持续可见文件名 / 尺寸 / 格式 / 来源徽标与主色色板，点击卡片色板可直接筛选相近主色
- **专业画布布局**：支持 Eagle 式瀑布流、自适应画廊和列表三种视图；自适应画廊按素材原始比例自动拼行并填满可用宽度，Inspector 开合、窗口变化和密度调整时实时重排；画布设置可切换缩略图填满 / 完整显示，并独立控制名称、规格、信息徽标和整理标记；布局、密度与显示偏好按桌面和手机分别保存在本机，不写回 Vault
- **Inspector 面板**：点击素材右侧滑出 Eagle 式资产档案，展示大图预览、素材类型、状态标记、紧凑规格属性表、文件夹路径、标签、来源 URL、备注、素材 ID 与复制 / 下载 / 引用快捷入口；底部操作按预览、输出、整理和更多分组，点按预览区可直接进入全屏预览，点击色板可筛选相近主色，相关区可一键跳到同格式、同类型、同构图或不小于当前尺寸的素材
- **左侧导航**：文件夹树可展开/折叠；导航栏宽度可拖拽调节；文件夹右侧显示含子文件夹在内的总文件数；整栏支持隐藏/展开，状态存本地
- **左侧快捷入口**：收藏、待整理、已处理、最近查看、智能视图和疑似重复直接进入主导航
- **排序与筛选**：按修改时间 / 创建时间 / 名称 / 大小 / 格式排序；按类型筛选（图片 / 视频 / 文档 / 音频 / 其他）；高级筛选可按精确扩展名收窄，素材卡片和列表行的格式 chip 可一键筛同格式；当前视图显示已载入素材的类型分布、总大小、标签、来源数量和 Top 来源域名，素材卡片、列表行、Inspector 和概览中的文件夹 / 标签 / 来源域名均可点击以快速跳转或收窄当前结果
- **高级筛选**：支持按最小尺寸、文件大小范围、横图 / 竖图 / 方图、Eagle 原生主色板及颜色容差、有无标签、有无备注、有无来源 URL、来源域名、最低星级、收藏 / 待整理 / 已处理状态组合筛选
- **智能视图**：可将当前视图、排序、类型与高级筛选保存为侧栏入口，并显示条件摘要；内置未标签、未来源、待整理、未处理和已处理成果池等整理队列；URL 可恢复到指定智能视图，面板内可一键复制智能视图链接；自定义智能视图可导出 / 导入 JSON，便于备份或迁移整理工作流
- **Eagle 原生智能文件夹**：只读解析 Vault `metadata.json` 中的 Eagle 智能文件夹及嵌套结构，按原生格式、名称、标签、文件夹、来源、备注、尺寸、大小和时间等常用规则动态求值；桌面侧栏和 iPhone 搜索 / 更多均可直接进入，URL、刷新、增量加载与离线快照保留同一自动分类入口
- **Eagle 保护文件夹边界**：识别 Vault 中设置密码的 Eagle 文件夹及全部后代；相关素材在建立索引前即被排除，不会进入全部素材、标签、搜索、智能文件夹、相似素材、缩略图或原文件端点。桌面与 iPhone 仍显示明确锁定入口，点击说明安全边界，但不接收、保存或传输 Eagle 文件夹密码
- **索引状态**：查看最近一次扫描的文件数、文件夹数、标签数、扫描耗时与跳过统计
- **跨设备整理**：可为素材设置 1–5 星评分，或加入收藏、待整理、已处理，并自动记录最近查看；评分与清单保存在独立 Viewer 状态文件并跨设备同步，不写入 Eagle 库；整理数据可导出 / 导入 JSON，便于备份或迁移到另一台远程访问设备
- **自定义工作集**：可创建带颜色标识的项目集、灵感板或交付集，从卡片右键菜单、Inspector、全屏预览、移动端长按面板和批量选择中加入素材；工作集作为侧栏与手机“更多”入口跨设备同步，URL 可恢复到指定工作集，全部状态只写 Viewer、不改变 Eagle 文件夹
- **Viewer 独立笔记**：Inspector 可编辑审片意见、用途和交付说明，输入自动保存并跨设备同步；卡片、快捷面板显示笔记状态，搜索可同时命中 Eagle 原始备注与 Viewer 笔记，高级筛选和智能视图可按有无 Viewer 笔记组织审片队列；笔记只写 Viewer 状态，不修改 Eagle 元数据
- **审片点位与时间标记**：Inspector 可为图片记录归一化画面点位，也可为视频/音频记录时间点评论；标记编号会叠加在预览图并显示在卡片状态中，文字可被全局搜索命中，支持跨设备同步、离线待同步和整理数据导入导出，始终不写入 Eagle Vault
- **相似素材**：Inspector 会用本地只读索引中的主色、构图、尺寸、格式、标签、来源与文件夹综合排序相近素材，显示匹配分数和依据并可连续跳转；不依赖 Eagle AI 插件，也不会上传素材或修改 Vault
- **低干扰反馈**：收藏、待整理、已处理、复制引用、刷新资源库等高频动作使用应用内 toast 确认，减少移动端浏览时的打断
- **远程更新感知**：前台轻量检测挂载 Vault 的目录与元数据变化；发现 Mac 端 Eagle 新增、删除或整理素材后提示“载入更新”，由用户确认后原位刷新，不打断正在进行的预览、多选或审片
- **命令面板**：支持 `Cmd/Ctrl+K` 快速打开视图、标签、文件夹、智能视图与工具入口
- **疑似重复**：按文件大小、尺寸与格式找出可能重复的素材组
- **全库色谱**：聚合 Eagle 原生素材色板，按色相与明度生成可浏览的颜色索引；桌面侧栏和 iPhone“更多”均可进入，点击色组即可筛选相近主色素材
- **随机漫游**：参考 Eagle 的随机模式，从全库或指定素材类型抽取 24 项组成可复现的接触表；桌面适合快速扫片，iPhone 以横向分页卡片探索，同一 Seed 链接可分享、刷新恢复并保存为离线快照
- **悬停预览**：鼠标悬停缩略图 300ms 后显示大图预览；图片悬停优先使用缩略图链路，`pdf` 支持悬停预览
- **卡片快捷操作**：桌面端悬停素材卡片时浮出预览、详情、收藏、待整理、已处理快捷按钮；移动端卡片会把收藏、待整理、已处理显示为带文字的紧凑状态胶囊，不必长按也能看懂整理状态；卡片路径、列表路径、右键菜单和移动端长按面板可直接打开所在文件夹，并自动滚动定位和短暂高亮原素材；有来源 URL 的素材可从卡片、列表、Inspector、预览 HUD、桌面右键菜单和移动端长按面板一键按同来源站点筛选；含色板素材可从右键菜单或移动端长按面板按“同主色”收窄；移动端长按面板会显示已选中 / 已收藏 / 待整理 / 已处理状态，并按打开、发现相近素材、整理、输出分区呈现，状态即时同步到角标和侧栏清单
- **预览与下载**：图片 / 视频预览；单文件下载为原文件名；多选后「打包下载」为 ZIP（按文件夹名/文件名命名，重名加序号）
- **审片胶片条**：全屏预览底部显示当前可预览素材缩略图，当前项高亮，点击可快速跳转到同一视图中的其他素材
- **连续审片**：移动端“更多 → 继续审片”可直接打开未处理队列并预览第一张可预览素材；手机全屏预览顶部 HUD 显示格式、尺寸、大小、来源站点、文件夹、标签和收藏 / 待整理 / 已处理状态，点击来源、文件夹或标签可退出预览并跳到对应上下文；底部保留详情、收藏、待整理、处理和更多五个主动作，左右滑动有跟手反馈，图片 / 音频预览可下滑关闭；在未处理队列中点“处理”会自动前进到下一张可预览素材，队列末尾会关闭预览并刷新结果
- **音频试听**：音频素材可直接打开沉浸式播放器，展示格式、时长、BPM 和原生播放控制，适合远程试听素材库声音文件
- **媒体预览增强**：图片预览支持放大、缩小、适应窗口、原始尺寸、水平翻转与 90° 旋转；移动端可双击图片在适应窗口和细节放大间切换，也可双指捏合缩放并拖动查看细节；视频预览提供水平翻转、旋转、倍速和循环播放，所有变换只作用于当前浏览会话，不修改 Vault 文件
- **远程字体样张**：`ttf` / `otf` / `woff` / `woff2` 在网格和 Inspector 中直接以字体样张呈现；全屏 Type Lab 可切换中文、Latin、数字预设，输入自定义文字并实时调整字号。字体仅从只读 Vault 临时加载到当前浏览器，无需安装，也不写入设备或 Vault
- **Office Quick Look**：`doc` / `docx` / `xlsx` / `pptx` 不再只能下载；网格显示 W / X / P 专业封面，Inspector 按需生成首屏摘要，全屏文档舞台可阅读旧版 Word 的可提取文字、Word 正文与表格、Excel 首个工作表、PowerPoint 幻灯片文字。旧版 `doc` 在 macOS 使用系统 `textutil`、Docker 使用受限的 `antiword`；所有解析均有文件、输出、执行时间、XML 或条目上限，不执行宏、不调用 Office、不修改原文件
- **XMind Quick Look**：`xmind` 在网格显示导图封面，Inspector 按需读取主题摘要，全屏在桌面展开为导图画布、在 iPhone 收敛为纵向知识树。兼容 `content.xml` 与 `content.json`，设有文件、节点和深度上限，不读取附件、不运行链接、不修改原文件
- **Eagle 缓存 Quick Look**：Graffle、Numbers、MindNode 等浏览器无法直接渲染的专有格式，只要 Eagle 已生成缓存图，就能从卡片或 Inspector 进入暗房式全屏预览；支持适应窗口、1:1、缩放、翻转、旋转、iPhone 双击与捏合，并明确标注“Eagle 缓存预览”，下载仍返回原始专有文件
- **导出**：当前列表导出为 CSV（左键）或 JSON（右键）；多选后可单独导出已选项
- **多选模式**：一旦进入选择状态，点击卡片会继续选择 / 取消选择而不是误开详情；支持 Shift 直接点击进入范围选择和框选；批量托盘显示已选数量、总大小、类型构成、当前视图范围和缩略图预览，支持反选、批量复制链接 / 信息 / Markdown 引用；选中卡片和列表行会有明确高亮；移动端会切换为整理优先的底部胶囊，直接收藏、加入待整理、标记已处理或移出当前队列，并通过“输出”抽屉提供复制链接、复制信息、Markdown 引用、CSV/JSON 导出和 ZIP 打包下载，完成动作后给出轻量视觉反馈；在智能整理队列中完成动作后会自动刷新结果
- **图片对比台**：选择 2–4 张图片即可进入暗房式并排审阅，桌面支持同步缩放、同步拖拽、适应窗口与 1:1 检查；iPhone 使用横向分页卡片切换，保留素材名、格式、尺寸和独立缩放状态；超过 4 张时明确取前 4 张，非图片不会混入
- **详情浏览**：Inspector 支持上一项 / 下一项切换，键盘可用 `← / →`；关闭详情或全屏预览后会回到并短暂高亮刚查看的素材，滚远后也可用“回到当前项”浮动胶囊重新定位，长列表里不丢位置
- **素材分享**：Inspector、右键菜单、移动端长按菜单和全屏预览可复制 / 调用系统分享当前素材深链接，另一台设备打开后直接恢复详情；iPhone / 支持 Web Share 的浏览器还可把 64 MB 内原文件直接交给系统分享，用于“存储到文件”、AirDrop 或其他 App，不支持的格式、浏览器和大文件会明确引导使用下载；也可复制 Markdown / HTML / 文本引用片段，便于把远程 Vault 素材嵌入笔记、文档和网页
- **手动刷新索引**：前端工具栏可一键刷新资源库缓存，无需重启服务即可重新扫描 NAS 上最新内容
- **复制**：图片类素材可复制到剪贴板（需 HTTPS 或 localhost）
- **快捷键**：j/k 或 ↑↓ 导航、Enter 预览、Space 多选、Shift+Space 范围选择、Cmd/Ctrl+A 全选当前视图、Esc 取消选择或关闭预览/Inspector、`← / →` 切换详情前后项
- **快速跳转**：搜索框支持 `#标签` 直达标签视图、`/文件夹` 直达文件夹；标签区支持就地搜索
- **URL**：当前视图（文件夹/标签/最近/搜索/收藏/待整理/已处理、排序、筛选及当前打开素材）反映在地址栏 hash，可分享或刷新保持状态；内容工具栏和移动端 workbar / 更多面板可一键复制或调用系统分享当前视图链接
- **主题**：深色 / 浅色切换，默认深色，偏好存本地
- **PWA**：支持安装到主屏幕；iPhone Safari 会显示“分享 → 添加到主屏幕”的引导卡片，Service Worker 缓存静态资源和最近访问过的只读索引 JSON，弱网可打开界面并浏览离线快照，远程 Vault 断线时提供全局状态条和重连入口；从主屏幕打开时会回到 14 天内的上次浏览位置，过期记录会被清理并回到资料库，并提供全部素材、收藏、待整理、继续审片和成果池快捷入口

## 产品边界

Web 是完整工作台，目标覆盖 Eagle 最常用的远程工作流：多维搜索、文件夹与标签导航、密度可调浏览、列表模式、Inspector、智能视图、高级筛选、重复项、批量选择、导出和打包下载。

iPhone / iPad 直接使用同一套 Web 应用：在 Safari 打开远程地址后，按“分享”→“添加到主屏幕”即可获得接近 App 的独立窗口入口；主屏幕安装后再次打开会自动恢复到上次文件夹、标签、搜索、智能整理队列或素材详情；底部导航覆盖资料库、收藏、待整理、搜索和更多入口，更多面板可一键进入未处理队列和已处理成果池；保留浏览、搜索、预览、收藏/待整理/已处理、下载/分享等关键链路；复杂批量管理、重复项分析、智能视图管理和索引运维在大屏 Web 工作区中呈现。

弱网 / 离线模式只缓存只读 JSON 索引和缩略图，不缓存原文件下载、批量下载或状态写入请求。断线时如果本机已有对应接口缓存，页面会继续渲染离线快照并提示“正在浏览离线快照，重连后刷新 Vault”；有缓存结果时主内容区会显示离线 / 快照提示条，没有缓存的视图会显示专用离线空状态和重连 / 保存快照入口，避免把网络或缓存缺失误读成资料库真的为空。离线或远程不可达时，列表行、长按菜单、Inspector、全屏预览和批量 ZIP 中的原文件下载都会明确提示需要连接远程 Vault。移动端“更多 → 离线快照”会主动预热当前视图最多前三页索引、当前屏幕素材元数据和缩略图，适合在离开内网或 VPN 前保存一批可浏览内容；不同文件夹、标签、搜索和智能视图会进入最多 8 个入口的“离线视图库”，断网后可从“更多”直接恢复已保存视图；同一路由再次保存会更新而不会重复堆积。

评分、收藏、待整理、已处理、Viewer 笔记、工作集和智能视图采用离线优先同步：断网修改会立即保存在本机并标记“待同步”，系统恢复在线或手动重连时自动补传；若另一台设备同时修改，Viewer 会以最近服务器版本为基线进行三方合并，保留本机离线增删，而不是直接用服务器旧状态覆盖。

## 运行方式

### Docker（推荐，用于 NAS）

1. 将 NAS 上的 Eagle 库目录挂载到容器内 `/vault`。
2. 构建并启动：

```bash
# 修改 docker-compose.yml 中 volumes 为你的库路径，例如：
# volumes:
#   - /volume1/eagle/Design.library:/vault:ro

docker-compose up -d --build
```

3. 浏览器访问 `http://<NAS或主机IP>:8000`。

### 本地开发

```bash
cd eagle-viewer
uv sync
cp .env.example .env
export EAGLE_VAULT_ROOT=/path/to/your/Design.library
make dev
```

## 配置

| 环境变量 | 说明 | 默认 |
|----------|------|------|
| `EAGLE_VAULT_ROOT` | 库在容器内的路径（需挂载） | `/vault` |
| `VIEWER_PASSWORD` | 访问密码。设置后打开页面需先登录；不设置则无需认证 | 空（不启用） |
| `VIEWER_SECRET_KEY` | Session 签名密钥，建议随机字符串（如 `openssl rand -hex 32`） | 未设置时使用 `VIEWER_PASSWORD` |
| `VIEWER_API_TOKEN` | 自动化工具或 API 客户端使用的 Bearer Token；设置后 API 需要该 Token 或网页登录会话 | 空（不启用） |
| `VIEWER_STATE_PATH` | 收藏、待整理、已处理和保存视图的持久状态文件；应位于 Eagle 库挂载目录之外 | `data/eagle-viewer-state.json` |

## API（只读）

- `GET /health` — 无需认证的容器健康检查
- `GET /api/info` — API 版本、能力与可用认证方式，供自动化工具或 API 客户端连接检查
- `GET /api/tree` — 文件夹树（每个节点含 `count`：该文件夹及所有子文件夹内文件总数）
- `GET /api/items` — 全部文件（支持 `sort`, `dir`, `type`, `offset`, `limit` 及高级筛选；颜色使用 `color=#rrggbb&color_tolerance=72`）
- `GET /api/recent?days=7|30` — 最近 N 天素材（支持 `sort`, `dir`, `type`, `offset`, `limit`）
- `GET /api/folders/{folder_id}/items` — 某文件夹下子文件夹与素材（支持 `sort`, `dir`, `type`, `offset`, `limit`）
- `GET /api/tags` — 标签及数量
- `GET /api/smart-folders` — Eagle 原生智能文件夹树、规则摘要与命中数量
- `GET /api/smart-folders/{smart_folder_id}/items` — 只读求值指定 Eagle 智能文件夹（支持排序、类型、高级筛选与分页）
- `GET /api/library/stats` — 最近一次索引状态
- `GET /api/state` / `PUT /api/state` — 跨设备同步的保存视图、收藏、待整理与已处理状态
- `GET /api/duplicates?limit=50` — 疑似重复素材组
- `GET /api/random?seed=...&limit=24&type=all|image|video|document|audio` — 按 Seed 稳定抽取随机素材，同一索引和参数返回相同顺序
- `POST /api/items/resolve` — 根据素材 ID 批量解析当前元数据，用于同步清单
- `GET /api/tags/{tag}/items` — 某标签下素材（支持 `sort`, `dir`, `type`, `offset`, `limit`）
- `GET /api/search?q=...` — 搜索（支持 `sort`, `dir`, `type`, `offset`, `limit`）
- `GET /api/items/{item_id}` — 素材元数据
- `GET /api/items/{item_id}/snippet` — 文本文件摘要（目前支持 `txt`）
- `GET /api/items/{item_id}/document-preview` — 有边界的 `doc` / `docx` / `xlsx` / `pptx` / `xmind` 只读结构预览，不执行宏、脚本或导图链接
- `GET /api/items/{item_id}/thumbnail` — 缩略图（无则返回占位图）
- `GET /api/items/{item_id}/file` — 原文件（预览）
- `GET /api/items/{item_id}/file?download=true` — 原文件（下载）
- `POST /api/library/reload` — 重新扫描资源库并刷新内存缓存
- `POST /api/items/batch-download` — 批量打包为 ZIP（Body: `["id1","id2",...]`）

列表类接口返回：`items`、`total`、`offset`、`limit`、`nextOffset`、`hasMore`，以及各端点自有字段（如 `subfolders`、`tag`、`query`、`days`），供前端增量加载使用。

Eagle 密码保护文件夹返回 `423 Locked`；其中素材不会进入 Viewer 索引，因此素材详情、缩略图和原文件直链统一返回 `404`，避免从非导航入口绕过保护。

素材元数据同时暴露 Eagle 原生 `palettes`、`duration` 与 `bpm` 字段；Web Inspector 会显示色板和音视频信息。颜色筛选使用 RGB 欧氏距离，容差范围为 `0–442`。移动端长按素材时，快捷操作 sheet 会为含色板素材提供“同主色”入口，便于在 iPhone 浏览器里快速收窄到相近视觉素材。

自动化脚本或受信客户端可为任意 API 请求添加 `Authorization: Bearer <VIEWER_API_TOKEN>`。该 Token 应仅保存在系统密钥链、密码管理器或服务端密钥管理中；生产环境请始终通过 HTTPS 或可信内网访问。

状态写入使用 `revision` 做乐观锁。客户端先读取 `/api/state`，写回时携带返回的 `revision`；若其他设备已更新，服务端返回 `409` 和最新状态，避免静默覆盖。

## 库结构要求

Eagle 库目录应包含：

- `metadata.json` — 库级元数据（含 `folders` 树）
- `images/*.info/` — 每个素材一个子目录，内含 `metadata.json` 和媒体文件

与 Eagle 官方 Mac/Windows 端使用的库格式一致，直接使用同步到 NAS 的库路径即可。
